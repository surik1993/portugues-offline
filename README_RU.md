# Португальский офлайн — начальный проект

Это стартовый PWA-проект для iPhone с европейским португальским и русским интерфейсом.

## Что уже работает
- поиск по португальскому слову, русскому переводу, примерам и формам;
- избранное (localStorage);
- карточка слова с примером, переводом, примечанием и формами глагола;
- карточки для повторения, кнопки «Знаю» и «Повторить позже»;
- кэширование файлов Service Worker для офлайн-работы после первого посещения по HTTPS.

## Важно
В словаре сейчас только 25 демонстрационных записей. Это не готовый словарь на 2 000–5 000 слов. Для полной версии нужно добавить проверенную словарную базу и убедиться, что лицензия разрешает её распространение. Примеры и формы в начальной базе учебные; перед публикацией рекомендуется языковая вычитка носителем европейского португальского.

## Быстрый запуск на Windows
1. Распакуй ZIP.
2. Установи Python 3, если его нет.
3. Открой терминал в папке проекта и запусти:
   `python -m http.server 8000`
4. На компьютере открой `http://localhost:8000` для проверки.
5. Чтобы установить на iPhone и получить надёжный офлайн-режим, выложи файлы на HTTPS-хостинг. Для тестирования подойдёт статический хостинг, поддерживающий HTTPS.
6. Открой HTTPS-адрес в Safari на iPhone → кнопка «Поделиться» → «На экран Домой».
7. Открой приложение при наличии интернета один раз, дождись загрузки словаря, затем проверь в авиарежиме.

`localhost` на Windows доступен только на этом компьютере. Не вводи `localhost` на iPhone — он указывает на сам iPhone, а не на ПК.

## Работа без Mac
- Для PWA Mac не нужен.
- Разработка возможна на Windows, а Safari на iPhone используется для проверки.
- Публикация нативного приложения в App Store и сборка IPA — отдельный этап, обычно требующий Xcode/macOS либо облачной сборки.

## Как расширить базу
Файл `dictionary.json` содержит массив объектов:
- `id`: уникальный числовой ID;
- `pt`: слово/выражение;
- `ru`: перевод; несколько вариантов разделяй точкой с запятой;
- `pos`: часть речи;
- `example_pt`, `example_ru`: пример и перевод;
- `notes`: примечание;
- `forms`: формы глагола, сгруппированные по времени.

ID должны быть уникальными. Сохраняй UTF-8 и валидный JSON. Не используй словарные базы без проверки лицензии.

## Файлы
- `index.html` — интерфейс
- `styles.css` — оформление
- `app.js` — поиск, избранное, карточки и подробная карточка
- `dictionary.json` — стартовые записи
- `manifest.webmanifest` — параметры установки
- `sw.js` — офлайн-кэш
